This is a static portfolio dashboard, not a monitoring agent. It does not query Kubernetes, Jenkins, AWS, Prometheus or Grafana. Use the linked repositories and workflow history to verify recorded activity. The GitHub Pages site being available does not mean the lab cluster or cloud resources are running.
